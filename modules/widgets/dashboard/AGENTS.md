# DASHBOARD KNOWLEDGE BASE

## OVERVIEW
Central interactive hub of Yozakura. Tabbed interface with LRU-based lazy-loading for widgets, system controls, media, AI tools, clipboard, notes, and tmux management. Opened via the Notch overlay.

## STRUCTURE
- **Root**: `Dashboard.qml` — Orchestrates LRU logic, the header + tab content frame, and open/close animations; the widgets tab loads the home named by `layout.dashboard.home` (`DashboardTabs.homeOf`: `stage` default, `composed`, `bento`). `DashboardSwipe` = vertical swipe between tabs.
- **Header**: `stage/StageHeader` on every tab: the time (large), date and weather on the left (the idle stage hero shows the time and weather itself, `showClock`); `stage/StageTabs` (visible tabs in `layout.dashboard.tabs` order as one kit `Segmented` pill group, the current tab on the sliding accent pill with the brush signature; scroll to step; segments named `dashTab_<id>`), the bento edit toggle (widgets tab in bento mode) and settings on the right. Tabs are registered in `DashboardTabs.js`; a tab's index there is stable (`GlobalStates.dashboardCurrentTab`), the config only sets header order/visibility (settings editor `modules/settings/editors/DashboardTabsEditor.qml`). Ctrl+Tab / Ctrl+Shift+Tab step through them.
- **Stage home** (`stage/`, default): natural about 876 x 560 (header 56, body ~440, metrics 44; `tests/dashboard-stage.test.py` keeps it within 900 x 600). `StageView` composes the left column, as wide as the tile row: `StageHero` (the player `StageHeroPlayer`, horizontal: cover with a soft shadow, bold title, artist, the wavy `PositionSlider` timeline, one transport row elapsed / prev / play / next / length; the art's tone (`StageTone`) floods the card while playing (`StageModel.floodTone` + `tintAlpha`, `layout.dashboard.heroTint`); idle: `StageHeroIdle` greeting + large clock + weather on a quiet accent wash; player and idle share one natural height and cross-fade with a rise), `StageToggles` (ONE row of seven square kit `Tile`s; Wi-Fi / Bluetooth / mic carry a corner caret = detail) and `StageLevels` (three slim `LevelSlider`s, tonal fills, caret zones open the output / input lists). `StageRight` holds `StageNext` (Pomodoro, khal events, timers, reminders: `StageNextLead` + `StageNextRow`s in a ListView over `KeyedListModel`), `StageWeek` (day pills, today solid, one highlight slides to the hovered / focused day; opens the month) and `StageNotifications` (`StageNotificationCard`s, 2 whole cards, 3 with room; keyed list: cards slide in, dismissed ones slide out and the gap closes, clear-all sweeps with a stagger); a detail (`home/HomeDetail`: month, wifi, bluetooth, output, input) slides over the right column (overview fades out early, detail in late, "Done" / Esc back); the left column never moves. `StageMetrics` strip of `StageMetric` capsules (values roll, `Sparkline` slides on append; `layout.dashboard.showMetrics`, opens the metrics tab). Empty states share `StageEmpty`. Motion: open = one `reveal` animation staggering hero, controls, right column, metrics (`Motion.glide` + `Motion.delay`, none on close; `playReveal()`); tabs cross-slide in header order (`Dashboard.qml` TabLoader); everything inside uses `Motion.micro` / `Motion.glide` / `Motion.spring` (<= 220 ms). Keyboard: Tab in reading order, arrows move spatially (`StageNav.js`, `tests/dashboard-stage-nav.test.cjs`), Enter / Space activate, Left / Right adjust sliders, Delete dismisses a card, Esc closes a detail before the dashboard; the first focus is play (first tile when idle) without a ring until the keys move (`FocusState`). A screen shorter than natural switches `compact` (shorter icon-only tiles, slimmer tracks, one notification card). Pure helpers `StageModel.js` (`tests/dashboard-stage-model.test.cjs`), renders `tools/render/dashboard_render.py --variants stage,stage-idle,stage-empty,stage-low,stage-narrow,stage-month,stage-flat,stage-focus`, motion contact sheets `tools/render/dashboard_motion_render.py` (open, tab, detail, dismiss, clear, arrive, track, stop, toggle).
- **Composed home** (`home/`): `HomeView` (player, toggles, levels | month, notifications, details). Its `HomeToggles` / `HomeLevels` / `HomeNotifications` are the quiet icon-row / line-slider versions; the stage has its own (`Stage*`).
- **Sub-tabs** (each a directory):
  - `widgets/`: bento grid. `WidgetRegistry.js` (host-agnostic widgets `{id, url, labelKey, icon, minW/H, maxW/H, defaultW/H}`, `defaultGrid(cols)`; a widget fills its tile and may declare `cellW`, `cellH`, `compact`), `BentoGrid.js` (pure layout: normalize/move/resize/add/remove; `tests/bento-grid.test.cjs`), `BentoView` (grid + edit mode, saves `layout.dashboard.grid` through `commit`), `BentoTile`, `BentoToolbar`, `WidgetPicker` (`tests/bento-edit.test.py`). Shared base `HostWidget` (cellW/cellH/compact/options/ink/k/framed; the desktop loads `CalendarWidget` and `WeatherWidget` from here). Every widget is one kit `Group` filling its tile (`fill: true`, `bare: !framed`; label + content, the box follows the visual language) built only from `qs.modules.components.kit`, and drops secondary detail at small sizes instead of clipping. Widgets: `FullPlayer`, `QuickControls` (+ `ControlToggle`), `CalendarWidget` (+ `CalendarModel.js`, `CalendarEvents`; a narrow tile is a day card), `SpecialsPanel`, `NotificationHistory`, `LevelsColumn`, `WeatherWidget`, `MetricsSummary`, `time/` (`PomodoroWidget`, `WorldClocksWidget`, `AgendaWidget`; shared with the bar clock popup: `PomodoroModel`, `PomodoroLengths`, `WorldClockSource`, `WorldRows`, `AgendaRows`). Text/glyph helpers: `WidgetFormat.js` (`tests/widget-format.test.cjs`). Behaviour: `tests/bento-widgets.test.py`; renders: `tools/render/widgets_render.py`.
  - `controls/`: live device panels (Wi-Fi, Bluetooth, audio mixer, EasyEffects), also shown by the settings Connect pages (`modules/settings/connect/ConnectPage.qml`). Every setting lives in the schema-driven settings window (`modules/settings`).
  - `assistant/`: `AssistantTab` (1196 lines) — AI chat interface.
  - `clipboard/`: `ClipboardTab` — Searchable clipboard history. `ClipboardTabBase` holds state/actions, `ClipboardTab` the layout and keys; parts: `ClipboardSearchBar`, `ClipboardList` + `ClipboardItemDelegate` (row, icon, options menu, confirm actions), `ClipboardPreviewPanel` (image/text/link/file previews, metadata); pure helpers in `ClipboardView.js` (`tests/clipboard-view.test.cjs`), behaviour in `tests/clipboard-tab.test.py`.
  - `notes/`: `NotesTab` — state + list actions; `NotesStore` (index.json + note files), `NotesListPanel`/`NoteListItem`/`NoteItemOptions`/`NoteConfirmButtons` (list), `RichTextEditor`+`RichTextFormat`, `MarkdownEditor`+`MarkdownFormat`, `NoteToolButton`. Test: `tests/notes-tab.test.py`.
  - `tmux/`: `TmuxTab` — Tmux session manager (state + actions); `TmuxSearchField` (keyboard flow), `TmuxSessionList` / `TmuxSessionDelegate` / `TmuxSessionOptions` / `TmuxConfirmActions` (rows), `TmuxPreviewPanel` / `TmuxPanesPreview` / `TmuxWindowsBar` (preview), `TmuxProcesses` (tmux calls), `TmuxModel.js` (commands, parsers, row geometry; `tests/tmux-model.test.cjs`, `tests/tmux-tab.test.py`).
  - `emoji/`: `EmojiTab` (934 lines) — Emoji picker with search.
  - `metrics/`: `MetricsTab` (987 lines) — Real-time CPU/RAM/GPU/disk monitoring.
  - `wallpapers/`: `WallpapersTab` / `Wallpaper.qml` — Wallpaper browser and manager. `Wallpaper.qml` (per-screen window + the manager API on `GlobalStates.wallpaperManager`) delegates to `WallpaperScanner` (folder/subfolder scans, fallback), `WallpaperColorPresets`, `MatugenRunner`, `WallpaperCacheJobs` (thumbnails, lock screen frame); rendering is `WallpaperImage` (slots `WallpaperSlot`, `StaticWallpaper`/`VideoWallpaper`, shader `WallpaperTransitionLayer`). `WallpapersTab` = top bar (`WallpaperToggle` x3, `SchemeSelector`), `FilterBar`, grid (`WallpaperGridCell`, `WallpaperGridHighlight`). Tests: `wallpaper-manager.test.py`, `wallpapers-tab.test.py`, `wallpaper-transition.test.py`, `depth-video.test.py`.
  - `kanban/`: Kanban board for task management.

## CONVENTIONS
- **LRU management**: Use `shouldTabBeLoaded(index)` for conditional `Loader.active`. Tabs evicted when exceeding cache limit.
- **Keyboard flow**: Components implement `focusSearchInput()` so root can forward focus on open.
- **UI primitives**: ALWAYS use `StyledRect` variants (`"pane"`, `"internalbg"`, `"focus"`) for containers.
- **Service bindings**: Connect directly to service singletons (`NetworkService`, `Audio`). No prop-drilling.
- **Large files**: Most tabs exceed 900 lines. Edit with care; use targeted line ranges.

## ANTI-PATTERNS
- Creating tab content without LRU integration via `TabLoader`.
- Prop-drilling service state through parent components instead of importing singletons directly.
- Using `Rectangle` instead of `StyledRect` for any container.
